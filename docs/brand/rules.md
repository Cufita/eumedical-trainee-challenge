# Eumedical brand rules

## Purpose
This guide captures the non-negotiable visual and interaction rules that the product must follow so the public site and the patient experience feel like the same company.

## Core identity
- Brand name: Eumedical
- Primary color: navy `#1e4865`
- Supporting green: `#79b19c` / `#2f6653`
- Accent gold: `#e79f1a` / `#efbc0b`
- Backgrounds: white, pale gray, and subtle navy-green gradients
- Graphic motif: the plus/cross symbol is a recurring brand element, never a generic bullet

## Typography
- Headlines: Fredoka
- Secondary labels: Didact Gothic
- Body copy: Arial
- Use a clear hierarchy and avoid decorative text treatments for editorial paragraphs

## Visual language
- Premium but warm medical-tech aesthetic
- 45° gradients and soft geometric forms
- Minimal patterns, no stock-photo clutter or generic template cards
- Favor clear, human messaging over decorative density

## Interaction rules
- The most urgent patient action must remain visible and primary: joining a live consultation
- Side navigation must preserve orientation and context in the patient area
- Empty states should guide the user to the next action instead of only saying “no data”
- Maintain accessible contrast, visible focus, and reduced-motion support

## Design boundaries
- Do not reinvent the brand in a generic SaaS style
- Do not duplicate the same content blocks or card patterns without a clear structural reason
- Do not compromise the real Eumedical brand book for tool heuristics alone

## Source of truth
Use the Brand Book PDF provided by Eumedical for the hiring process (not included in this repo — confidential company material) as the authoritative reference for visual details. This rules file is the working summary for product decisions and implementation reviews.
